`haugland_2608.04542v1.html` is a preserved copy of Jan Kristian Haugland,
*A Moser-spindle-free 5-chromatic unit distance graph on 2131 vertices in the
plane*, arXiv:2608.04542v1, dated 5 August 2026.

- Source: https://arxiv.org/html/2608.04542v1
- Source license: Creative Commons Attribution 4.0, as stated in the HTML.
- Retrieved: 10 September 2026.

The implementation uses the coordinates in Section 2 and Appendix A's 231
integer paths as input data. Every path endpoint is checked exactly in the
cyclotomic field. Exported graph files include the SHA-256 of this source.
The exact T5/T6 constructor is independently derived by meeting unordered
half-path sums and taking all submultiset sums; it does not use the paper's
floating-point separation lemma.

This source constructs a graph that is not 4-colorable. It does not establish
non-6-colorability, and reproducing it is not the requested success result.
